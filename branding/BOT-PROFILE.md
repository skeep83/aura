Логотип: светящееся кольцо-«аура», которое прорывает искра. Всё значимое — внутри круга, поэтому круглая обрезка Telegram ничего не съедает. Цвета: `#36d1f0 → #4a86f7 → #5a4ff0`.

## Тексты (бот выставляет их сам при запуске)
Имя, короткое и полное описание и команды задаются через Bot API в `src/bot-profile.js` — на английском по умолчанию и на русском для русскоязычных. Руками нужно только аватар, картинку описания и Mini App.

**Имя:** Aura — видеочат со всем миром · *EN:* Aura — video chat with the world

**Username (проверьте, что свободен):** `@aura_videochat_bot`, `@auravibe_bot`, `@aurachat_live_bot`

**Короткое описание (профиль, ≤120):**
> Видеочат со случайными людьми со всего мира. Свайп — новый собеседник. Подбор по языку, игры, взаимный вайб ✨

> *EN:* Random video chat with people worldwide. Swipe for the next person. Match by language, play games, catch the vibe ✨

**Полное описание (экран «Что умеет этот бот?», ≤512):**
```
✨ Aura — видеочат с людьми со всего мира прямо в Telegram.

• Свайп — и новый собеседник
• Подбор по языку: практикуй английский с иностранцами
• Взаимный «вайб» — обменяйтесь контактами, если понравились друг другу
• Игры в звонке и маска для стеснительных

Без регистрации и записи видео. Только 18+, автомодерация.

Жми «Начать» 👇
```

**Команды** (на случай ручной настройки — @BotFather → `/setcommands`):
```
start - Открыть видеочат
room - Рулетка для своего канала
invite - Пригласить друга — Premium обоим
events_off - Не напоминать об Aura Hour
terms - Правила и конфиденциальность
paysupport - Помощь с оплатой
```

## Mini App (@BotFather → `/newapp`)
- **Title:** Aura
- **Description:** Видеочат с людьми со всего мира: свайп, подбор по языку, игры и взаимный вайб ✨
- **Photo:** `cover-ru-640x360.png`
- **Web App URL:** `https://<ваш домен>`
- **Short name:** `app` → впишите в `.env`: `MINIAPP_SHORT_NAME=app` (ссылки станут вида `t.me/<бот>/app?startapp=…`)

Затем: Bot Settings → Configure Mini App → Main Mini App — кнопка «Открыть» появится прямо в профиле бота.
